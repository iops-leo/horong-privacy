🏮 계정·데이터 삭제 요청

언어 한국어 · English

앱: 호롱 – 아카리 라이트업 논리 퍼즐(com.leo.horong) · 개발자: 쇼츠스토리 스튜디오

요약: 호롱은 회원가입이 없습니다. 서버에 데이터가 저장되는 건 등불 순위에 직접 참여했을 때뿐이고, 그 데이터는 앱 안에서 직접 삭제할 수 있습니다. 앱을 지우기 전에 아래 절차를 이용해 주세요 — 앱만 삭제하면 서버의 순위 데이터는 남습니다.

앱에서 삭제하기 (권장)

  1. 호롱을 엽니다.
  2. 홈 우상단 설정(⚙) 을 누릅니다.
  3. 아래 정보 항목에서 「순위 계정 삭제」를 누릅니다.
  4. 확인 창에서 「지울래요」를 누르면 즉시 삭제됩니다.

「순위 계정 삭제」 항목은 등불 순위에 참여한 경우에만 보입니다. 참여한 적이 없다면 서버에 지울 데이터가 없습니다.

이메일로 요청하기

앱을 이미 삭제했거나 위 절차를 쓸 수 없다면 support@viralpulse.net 으로 요청해 주세요. 확인을 위해 순위표에 표시되던 프로필 이름과 #번호 (예: 「따뜻한 호롱이 #1234」)를 함께 적어 주시면 빠릅니다. 요청은 접수 후 30일 이내에 처리합니다.

삭제되는 데이터 / 보관되는 데이터

데이터처리
익명 계정 식별자(uid) 삭제 — 계정 자체가 사라집니다
프로필(이름 조합·아바타·지역) 삭제

「최근 클리어」 피드의 내 기록 삭제 — 남는 항목도 최대 90일 뒤 자동 삭제
기기 안의 게임 진행(여정·데일리·설정) 기기에만 있으므로 앱을 삭제하면 함께 삭제됩니다. 순위 계정 삭제로는 지워지지 않습니다(플레이 기록을 잃지 않도록 일부러 나눠 뒀습니다)
익명 이용 통계·오류 보고(Firebase) 개인을 식별하지 않는 집계 데이터로, Google의 보관 정책을 따릅니다
